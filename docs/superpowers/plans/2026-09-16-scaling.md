# LP Scaling Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add reversible row and column scaling for floating LPs, enabled by default, while returning and reporting values in original units.

**Architecture:** `SolverOptions` selects scaling; `transformations.jl` builds a scaled copy and records factors; `solve` passes that copy to either simplex algorithm and unscales the result. Progress evaluation uses the original objective and unscaled structural variables. Existing original-model certification remains the final gate for optimal results.

**Tech Stack:** Julia 1.13, `SparseArrays`, `MathOptInterface`, `Test`.

**Spec:** `docs/superpowers/specs/2026-09-16-scaling-design.md`

## Global Constraints

- Scale rows and columns only; preserve the objective constant and sense.
- `:auto` scales floating models and leaves rational models unchanged; `:off` always skips; `:on` rejects rational models.
- Use powers of two and retain factor 1 whenever a candidate would make a nonzero input zero or a finite input nonfinite.
- Keep input arrays unchanged, including stored BigFloat values and precision.
- Validate optimal primal and objective values against the original model.
- Work only in the `feature/scaling` worktree; do not include generated `Manifest.toml` in commits.

- [ ] **Step 3: Implement the transform.** For each row, find `m = maximum(abs, nonzero values)`; use `frexp(m)` to derive exponent `e-1`, then `ldexp(one(T), e-1)` as the candidate. Test every affected matrix value and finite row bound with `ldexp(value, -(e-1))`. Accept only when all results are finite and every originally nonzero result stays nonzero. Apply accepted row shifts to a copied CSC matrix and bound vectors. Repeat for columns using the row-scaled matrix; test column bounds with `ldexp(value, e-1)` and objective coefficients and matrix values with `ldexp(value, -(e-1))`. Construct a new `LinearProblem{T}` and return it with `Scaling(row_factors, column_factors)`. For `BigFloat`, calculate each shift inside `setprecision(BigFloat, max(precision(value), precision(BigFloat)))`.

```julia
_shift(value::T, exponent::Int) where {T<:AbstractFloat} = ldexp(value, exponent)

function _shift(value::BigFloat, exponent::Int)
    setprecision(BigFloat, max(precision(value), precision(BigFloat))) do
        ldexp(value, exponent)
    end
end

_safe_shift(value, exponent) = begin
    shifted = _shift(value, exponent)
    isfinite(shifted) && (iszero(value) || !iszero(shifted))
end
```

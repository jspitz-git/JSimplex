## Algorithm and ownership

The private producer/consumer `column_ftran!` prepares the entering column from captured CSC input (or -identity artificial column). Ordinary PFI/triangular full-base FTRAN receives this original sparse RHS before update histories. BTRAN and direct lower-only backends are excluded. Native reference owns an independent factor and RHS; candidate owns a second native fallback factor plus combined extracted CSC L/U/F (L/U sorted; F retains native extraction order), P/Q/R/Rs and private scratch. No external mutation/concurrency during a call; replacement builds a new factor then invalidates exports, failed replacement preserves old state. No symbolic reuse.

Three arms: native KLU, all-block exported Julia control, fused graph-local exported Julia. The last two share an owned cache sequentially; all three include RHS preparation, destination checks, solve, output scatter and minimal scalar observations. Maxheap chooses descending block IDs, preserving that exported control's topological and within-block arithmetic order. F traversal itself enqueues structurally nonzero dependencies: no separate per-call graph census/CSR. Cancellation does not prune dependencies. KLU's Rs is in final pivot row order. Native packed order may differ after export sorting, so comparisons to native use unchanged residual bounds rather than a bitwise claim.

Freeze eligibility before results: n>=4096 and >1 block, otherwise use the same NativeOnly method as reference, before export allocation. For eligible contexts source stored count >= n/2 routes native; enqueued block coefficient/division weight >=75% of full routes native, including sunk private computation. Nonfinite/negative-zero producer values and nonfinite active pivots route native. Destination is untouched until successful scatter or native fallback, original RHS retained. No new tolerance, precision or pivot rule. Small forced contexts are explicitly cold/control tests only, except labeled coupled256-forced diagnostic control.

Input/source/private Float64 buffer overlap rejected before writes using pointer intervals, including partial unsafe_wrap overlap. Own exports validated once for finite coefficients/positive scales, permutation, diagonal, triangular and block ordering; only owned immutable indices support unchecked inner loops. Full input RHS unknown-support call uses native fallback. Generic public API and hostile private-field mutation are out of scope.

## Work and retained memory

Setup: one factorization per context; eligible candidate one combined native sort/extract, O(n+nnzL+nnzU+nnzF) validation, inverse P and row-to-block map, block weight totals. Exports duplicate factors retained by native fallback. Primitive retained payload: 8*(Lp+Li+Lx+Up+Ui+Ux+Fp+Fi+Fx+P+Q+R+Rs lengths) + rowpos/block/work/rhs 32n + weights/heap 16nb + marks4nb; headers/native reported memory separately. NativeOnly retains RHS8n and native object. Setup compile/cold and warmed factor/context measurements separate from repeated calls.

Each local call: RHS fill O(n), source scatter O(nnzcol), work clear O(n), same-source scale/scatter and seed O(nnzcol), active L/U/F coefficient visits, maxheap O(reached blocks log nb), final Q scatter O(n). Finite checks once per active L/U pivot and source value. Constant owner overlap checks. Epoch rollover adds one marks clear O(nb), explicitly tested. Full control gathers/scales all n, visits all blocks, scatters n. Native does RHS fill/scatter, copy n and native solve. No claim that skipped arithmetic eliminates dense fills/scatters or native/Julia language differences. Fallback incurs any sunk local work plus whole native solve. Timing includes scalar route/checksum accounting; batch keeps one 7-element route vector allocation per sample for every arm. No full output hash/residual/certificate scan inside windows. Source-derived weights count stored L offdiagonals + U entries + F slots, not exact flop/call instrumentation or elapsed time. Processed-block/weight counters cover exported Julia work only: a native route reporting zero still performs a complete native solve; budget fallback additionally includes sunk exported work. The all-block control gathers/scales each work slot without a redundant preceding clear.

## Oracles and decision

Ordinary Test, no custom recorder or manual testset stack. For every query in both cold cycles: each arm finite normalized original-B residual <= min(1e-10,128*n*eps64); local/native relative output difference <=1e-6; graph vs all-block control equal nonzero bits, both-zero allowed and sign differences recorded. First query/case/arm gets 256-bit directed residual enclosure outside timing, not raised production precision. Source A/B/export digests stable before/after; caches exercised repeatedly. Microtests cover reach order/budget restart, epoch rollover, partial overlaps, source preservation, independent scratch, real replacement invalidation, failed singular replacement, nonfinite and -zero fallback, scale overflow then reuse, dense unknown fallback and bad-output oracle sensitivity.

A meaningful local speedup must beat native whole-call time on representative runtime cases without numerical failure; sparse/dense/low-opportunity and fallback costs and memory are explicit. Report all arms and uncertainty; local-vs-full saving alone is not native KLU speedup. Even positive evidence is only fixed-base spike qualification, not unchanged public trajectory, scalar ownership, signed-zero, native memory/free or production rollout proof. Independent admission and result review must state unnecessary work/memory and numerical limitations. Preserve failures; no numerical retry except a separately admitted unchanged timeout-only extension.

# F13 — Reversible primal bound perturbation

Status: complete correctness verification and preset measurements passed. Parent: `9c3efaa` (F12). Adaptive behavior remains opt-in;
legacy is the default.

## Behavior

A completed stagnation window can expand the near-active finite bounds of basic
variables outward. The current primal values remain unchanged and feasible for
the expanded working LP. Fixed/free variables and nonbasic variables are not
shifted. Exact rational arithmetic remains unperturbed.

The F12 journal now owns an optional bound state with original/active lower and
upper vectors, a separate active flag, three-level escalation history, and a
cooldown. Cost-only perturbations do not allocate these vectors. Bound flags
and values are copied directly on restoration, including signed zero; the
input model and presolve metadata are unchanged. Basic-bound publication is
staged and cancellable before mutation. Basis recovery preserves the active
buffer ownership and applies a two-window cooldown, including before the first
bound action.

Margins use the user primal tolerance, deterministic index factors 8–23, and a
local bound scale between one and two. Three attempts scale margins by powers
of two, with a total displacement cap of 512 primal tolerances. Nonfinite,
unrepresentable, excessively rounded, inward, and over-cap candidates are
skipped. Finite bounds remain finite and outward expansion cannot invert a
valid interval. BigFloat calculations use stored workspace precision.

Automatic bound perturbation requires `adaptive_primal_perturbation`,
`adaptive_stalling`, and `feasibility_recovery`. The first switch defaults on
only in the adaptive strategy and supports a separate ablation. Original
primal invocations use this action; algorithm switches inside original dual
invocations do not enable it. Phase I, auxiliary workspaces, and terminal
cleanup disable the action. Phase II restores eligibility.

Before accepting an optimum or terminal proof with active expanded bounds,
the shared driver restores saved working bounds and costs, restores actual
problem costs, and recomputes/redispatches on the original LP. It shares the
same clock, completed-step budget, and bounded cleanup loop. An optimum outside
the original bounds is not accepted. Unrelated altered bounds without an owned
journal retain the existing rejection of infeasibility/unboundedness proofs.

## Limitations

F13 establishes reversible bound handling and original-model cleanup under
shared limits. These measurements do not demonstrate additional solved
coverage, a general speed improvement, or improved stability on independent
instances. The adaptive strategy remains opt-in.

Mapped dual diagnostics are available in 19 observations: 16 have zero dual
sign and complementarity error. The remaining three are the parent and both
current degen2 dual observations, all retaining the same strict infinite
complementarity diagnostic and dual sign error 2.955113931335518e-13 documented
in F12. The strict metric treats even a tiny nonzero price toward an absent
bound as infinite. Those values are preserved and do not constitute an
independent complementarity certificate. Other unavailable dual witnesses
remain explicitly marked in the artifact.

Kernel and ownership

candidate.jl:15-27 constructs a numeric F row incidence index, source-column map and inverse Q in O(n+zF), with no second factor numeric-value copy. Its transpose block weights sum the same LU-n+F coefficient work as the existing forward total, while attributing F to its source row. candidate.jl:47-81 uses an increasing heap and U-transpose ascending then unit-L-transpose descending CSC arithmetic. This is consistent with T=L*U+F=diag(Rs)^(-1)*B[P,Q], T-transpose*y=rhs[Q], and x[P]=y/Rs. Full/local use the same block-local coefficient order. Native packed order can differ; native bitwise equivalence is not claimed.

Unit RHS construction occurs after dimensions/private-buffer/partial-overlap/bounds rejection. Source unit RHS remains intact for all budget, nonfinite, invalidation and postscale fallback routes. Native fallback overwrites any partial destination from that original RHS. Generic input copies to owned RHS before output, so legitimate input/output overlap is safe there. The private native factor and exported arrays remain alive with the context; the scratch, heap and marks are single-caller. Explicit successful replacement installs a new factor and invalidates both graph flags; factorization failure leaves old state. Epoch rollover clears marks. Direct hostile field mutations/concurrent callers are outside this experiment's contract.

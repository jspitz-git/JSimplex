# MA-P: exact RHS propagation micro-experiment

User requests testing MutableArithmetics in RHS propagation. This is a new short, isolated presolver kernel experiment, not a rerun of MA-O. No production/test/environment configuration/master change or full presolver/LP/solver execution. CI stays disabled; HH reuse and automation stay disabled.

Reference wraps the exact current `_presolve_basic` selected-column RHS staging loop. Candidate changes only general exact rational multiplication and subtraction to private MA buffers. It preserves exact representability rejection, row order, zero/unit shortcuts and equal-bound sharing. Two private rational destinations and both MA buffers are created on EVERY call, including short/simple cases. Published Rational values borrowing scratch are deep copied; BigFloat conversion owns its result. No persistent cache or input writes. Source constructor counts are not allocation measurements.

112 fixed fixtures: Q, BigFloat 256/512, Float64; 1/32 nonzeros; dense column or odd-index sparse column; general/unit/zero/equal/free/shared-input/rounding-rejection. See fixtures.json and exact driver formulas. BigFloat stored and ambient precision are matched here; other rounding modes/mixed stored precisions and full presolver trajectories are not qualified. Reference and candidate compare to independently computed exact rational bound differences with explicit conversion checks. 1120 fixture flags, 12 scratch-poisoning flags and one negative snapshot control = 1133 flags in 117 records. Input values, scalar owners, retained results and ambient state checked. Mode-specific flags outside their mode are conditional, not universal identity proofs.

64 cost fixtures (general/unit/zero/equal). Each process: two untimed first calls per fixture; 3 warm and 7 measured alternating pairs; 16 complete calls per window. Three serial processes: 3840 windows, 61440 timed calls, 384 first calls; process 1 alone 336 correctness column calls plus 4 scratch microcalls and one isolated snapshot mutation control. Fresh scratch, exact conversions, representability checks, required output copies and changes vector are INSIDE each complete-call window. Fixture construction, oracle/snapshot checks and serialization are outside. No trace in timed kernels. Retained outputs are bounded by 32 staged entries per call; GC counters are allocation traffic, not native live memory/free proof.

Report short/simple regressions and GC; require zero measured compilation/recompilation. No tuning, retries, warmup extension or discarded outliers after observation.

# Installed-runtime compatibility evidence

The installed julia.h enum identifies PARTITION_KIND_BACKDATED_CONST=0xb and describes it as a temporary compatibility constant which prints a warning on access; previously guarded/failed/declared partitions may be backdated. The saved installed ELF disassembly is evidence from this actual library, not an assumed upstream version. No library was loaded and no Julia/C compiler/query/probe was run.

In jl_get_binding_value_in_world, kind0xb reaches0x6c00c. An additional task flag or option byte==2 takes the undefined-variable error branch. Otherwise the function sets the binding's warning bit, optionally calls print_backdate_admonition at0x6c04c and returns the stored partition restriction at0x6bfd4. That path does not test whether the returned constant is a function or a module. Installed jloptions.h aarch64 layout independently places depwarn at byte116, matching the option load. This is static ABI arithmetic, not a query of future runtime option values.

jl_declare_constant_val3 at0x6e4cc–0x6e4e4 writes kind0xb and the supplied constant value into prior partitions. jl_f_getglobal enters jl_eval_global_var with the task world; jl_eval_globalref checks its retrieved value and raises undefined-variable error only on a null result. Together with installed Base module-getproperty/getglobal and latest-invocation sources, this supports the generic constant compatibility mechanism, rather than assuming the RED function alone proves all module accesses.

The pinned command does not set --depwarn=error, does disable startup files, and does not run Revise or redefinition callbacks. The accepted RED's same runtime/loader command actually took the warning-compatible path.

## Loading and source identity

One ordinary package overlay contains the70 tracked src files and exact Project,
Manifest and LocalPreferences copies. Only src/primal_updates.jl differs: it is the
frozen S2-C candidate. The manifest's self dependency path is dot, so the overlay
project selects its own package source. The driver requires pathof(JSimplex) to be
the overlay source and checks the cost method source path. This is one module,
not method overwrite or a nested full-module isolation experiment. Runtime loading
is not yet demonstrated. An unexpected cache/source selection fails before work.

The reference cost function is the whole original final audit function with only
its name and four JSimplex qualifications changed. Its inverse is checked offline.
It runs beside the candidate using the same ordinary loaded module's unchanged
matrix, scratch, quality and policy implementations. No solver method is replaced.
The C regression file is included byte-identically; it runs only against candidate.
Its direct quality pairs already contain the original materialized-vector control.
The three integration bodies retain their original assertion oracles; no second
reference integration or historical driver rerun is claimed.

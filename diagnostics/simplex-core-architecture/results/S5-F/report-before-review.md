## State, accounting and output

Observer is disarmed through setup. After three equal-value detached working copies,
source baseline and budget are captured, then the observer is armed for transfer.
At the final event it increments one fixed counter, retains trial, and sets the stop
flag or throws SingularException(7). Other events do nothing. The stop closure only
reads the flag/counts true observations; throw has no false final-guard oracle.
DiagnosticObserverFailure.cause identity is saved before formatting/snapshots.
Returned nothing, retained fresh owner and source preservation are separate checks.
There are no solves, snapshots, I/O or source mutations in the observer.

Source before/after value/identity records compare numerics, journal/bounds and
histories, factor identity/update length, model/configuration/progress, cache and
pre-detachment checkpoint key. Mutable work is outside unchanged-state equality.
Fresh has independent journal containers and basis/model, active aliases, reset
history, preserved levels/cooldowns/activity, empty checkpoint and pricing cache,
new factor without updates, shared diagnostics/clock and typed configuration.
Copied finite input fields must carry 128-bit precision; reconstructed solution/
weight values are observations, not analytical replacements. Wider internal quality
arithmetic is not constrained. Ambient precision/rounding is checked restored.
No working result is asserted to be an original-model certificate.

Three capture groups implement S5-E's fixed schema: source 31 arrays/76 entries
before and after; fresh 26/63, totaling 88/215 per case, 176/430 overall. Scalars
are encoded into independent immutable tokens: rational strings of stored floating

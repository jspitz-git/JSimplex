## Construction/export/copy/refactor coexistence

Task1 build requests23+n+3S vectors plus BGSplitUpper. Then one genuine _factorize_basis, one exporter call, optional unchanged _direct_normalize_upper!, one direct bulk U build, and scratch/cache establishment. Those internal/native allocation and solve counts are not newly instrumented or bounded here. Markowitz has its own unchanged extraction. A custom exporter test is not genuine backend-ownership proof.

Normalization first allocates D(n), scans diagonals, allocates candidate values(nnzU), scans/validates all divisions, then copies values into the private exported U on success. Unsafe normalization returns nothing and leaves exported coefficients intact; partially allocated D/values remain transient until collection. Constructor then builds block storage directly from exported U/q, without a packed BG intermediate. During this build ordinary backend + L/U exports/p/q/scaling + normalization temporaries + new blocks/base/cache can coexist. The U export's CSC buffers and q are transient (q values copied into Int32 maps), not retained by block storage. Fallback additionally constructs ones(n), spdiagm identity CSC and collect(1:n) before block import; account for these even though the final U has only n entries.

Copy first copies ALL U retained capacities/holes/scratch through _sbu_copy, then _copy_backend, history container, work/spike and fresh row cache. It shares only read-only lower fields and immutable-by-contract history payload; fallback native backend copying is separate. It creates a fresh empty recycled container and no prepared cache. The source shared_update_count is published only after every explicit allocation succeeds. A failed storage copy leaves all source owner identities and state unchanged. The old graph plus new owned graph and backend-copy temporaries coexist; shared owners are not double-counted in a union graph. Other saved factors are additional roots.

Refactor calls the full constructor privately, with original backend/policy/normalization. It verifies concrete type before publishing all eight fields. Prior factor, new factor, exports, ordinary/native factors, normalization and copied buffers coexist until success/unwind; successful publication resets block high-water/history/cache to the NEW export. No reuse/compaction or mid-update reclamation is introduced.

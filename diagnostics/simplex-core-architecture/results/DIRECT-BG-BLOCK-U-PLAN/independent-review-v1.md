## Numerical and structural assessment

- Stable column IDs equal q[j], and row incidences sorted by those IDs agree with packed _ensure_bartels_golub_incidence! and the frozen adapter. Logical column position must be filtered through the inverse map during elimination. Import in stable-ID order through inverse q preserves that order in O(n+m), without a sort or repeated insertion.
- Physical row identity and logical row order are correctly separated. Adjacent logical rows occurring in the same column are adjacent entries, even when the positions straddle blocks. Swapping complete tuples and fixing two reciprocal handles is sufficient; single-row occurrences need no entry movement. Rotation correctly moves the carried tuple through each affected column and repairs moved handles before rotating maps. Its interval work is acknowledged, matching the packed stable-order principle.
- Handle semantics are coherent: relocation retains descriptor ID; entry movement repairs row handles; gap movement repairs row_back. Reserving a spare descriptor before exchanging extents avoids losing the displaced extent. Split16/17, right-descriptor merge, empty-block unlink and capture-next-before-recycle are all called out. Gap/source cursor reload after edits is essential because a source row's membership can be unchanged while its handles change. No stable-handle assumption escapes an edit/history/cache boundary.
- The design must use the source location as the adjacent-row insertion predecessor in elimination, as the frozen adapter does, rather than implement Task2 solely with a repeatedly searching generic _bgu_set!. The monotone merge/no-repeated-search contract and direct handles already require this; verify it in the source review.
- Contiguous solve prefixes preserve logical arithmetic traversal. Proving the last diagonal permits one exclusion per column, matching triangular_indices; missing/Hessenberg cases retain the fallback that skips the diagonal wherever found. No new full-U scan, mirror or coefficient conversion per solve is proposed. Signed/explicit imported zero behavior, cancellation, finite tracking, pivot checks/history ordering and pure-swap predicates are explicitly retained.
- Exception contracts distinguish primitive structural integrity from whole-update rollback. Reserve/stage before nonthrowing commit, checked widths and failure injection cover the material hazard; capacity reservations need not roll back. Multi-column swaps/rotations must remain nonallocating after validation. Refactor privately builds/publishes, copies own mutable storage, and shared history cannot be recycled. Prepared entering/DSE cache rules and scratch destination alias exclusions have explicit tests. This is a plan-level argument; only later source review and admitted tests can establish implementations satisfy it.
- Scope is Float64 private direct BG with two fixed native policies; unsupported precision, indexing and call variants reject before work. No claim extends to all repository precisions, public interfaces, FT/SS/HH or arbitrary backends. Fallback, normalization, singular/nonfinite/malformed and zero-size cases are explicitly planned.

## Work and memory accounting conclusion

The core formula16C+4R+28K+32n+656 is correct: one Float64 plus two Int32 arrays per slab entry, one Int32 incidence per row-capacity entry, seven Int32 descriptor arrays, eight Int32 n-vectors,32bin heads and33-entry Float64/Int32/Int32 scratch. Outer pointer payload8n+24S is additional; all backing reserves and headers must also remain separate. K must include free and unused descriptors, C includes retained holes, and R includes gaps. Initial tails minimize C but relocation can consume more descriptors/extents without increasing live nnz.

Setup has O(n+m) passes plus unchanged export/backend work. Each RHS adds per-block directory/descriptor access and per-entry Int32 index decoding but removes per-entry linked successor traversal; no speedup follows merely from that change. Every structural edit adds bounded tuple/reciprocal-handle traffic, row gap movement and possible full-row copies; column replacement additionally scans n and searches/moves affected rows. Swaps merge row degrees; rotations traverse affected intervals. Descriptor growth copies O(K), directory growth O(S), slab append initializes4096B without copying old coefficient slabs. Copy includes high-water C/R/K/S/history containers; refactor coexists with old owners and backend/export temporaries. Those are meaningful prospective costs, not native-peak measurements.

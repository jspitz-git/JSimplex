# BG export-workspace Task3 work and memory budget

Eight cells: original sparse32,dense32,sparse96,dense96 times native threshold_one and Markowitz default. Each process:3warm+7measured alternating pairs,20 lifecycle windows/cell,160 total/112measured. Each lifecycle constructs one factor, performs8 entering FTRAN+8 distinct DSE FTRAN,8updates,8BTRAN and refactors after4/8. Constructor includes original factorization, extraction, orientation if needed, validation, import and inner initialization. No reference manager is constructed/discarded on candidate path. Identical six UInt64 nested clocks are allocated inside each whole timer. Nested phases are subsets, not an additive reconstruction of pure backend time.

Timed totals:160 constructors,320 refactors,1280updates,2560FTRAN+1280BTRAN. Eight policy preflights add16 constructors/32refactors/no explicit API solves; actual native controls/defaults and paired modes captured at B0/B4/B8. Internal factorization/update work and conditional fallback backend copying are additional; no native-free or PREforward-complete claim. One synthetic zero-output orientation call is explicitly separate:2 scratch requests/64 payloadbytes, no genuine backend factorization/solve. Three importer controls call reference/candidate/probe once each, no factor/solver calls.

Untimed clones have exact full-file inverse: four candidate files with private names/types plus documented counter statements. Timed factories always call original _bgx_* candidate or packed DIRECT reference. Counters record allocator requests/payload, factorization/extraction/orientation/product/validation/refactor entries and index/normalized/raw/fallback stores. Counters before requests/calls count attempts; they do not observe hidden native internals. Probe diagnostics add one Dict of13Int counters and one peak Int Ref; clone methods do not modify production methods. Fixed three-factor probe uses11checkpoints (constructor; each8updates; two extra postrefactor). Every checkpoint compares full packed U/history/permutations/mode and records all three factor graphs plus candidate/probe caches; up to4 temporary packed-state materializations/checkpoint. Per-cell output destinations72*n Float64 entries; all3 paired outputs exact-bit compared and independently exact-rational residual audited. Source counters and graph scans are outside all measured windows.

Each probe build additionally records Base.summarysize((new_inner,backend,raw_export,owner)), once after successful private inner build and before publication. During refactor owner still holds old inner; metadata records a scalar peak, never retains those owners. This covers reachable Julia old+new+backend/export/workspace coexistence at that seam, not a universal execution peak or hidden native heap. Caches charge512+8cld(n,64), optionally32n, with original min(1MiB,P0/16) budget. Checkpoints after updates carry the last import budget; update forwarding neither recomputes it nor claims budget from changed live U. Fresh refactors recompute budget. Record sum of sampled cache charges and maximum; the sum is not simultaneous memory. Graph bytes include headers/backing storage; policy charge is not physical memory.

Timed output24*n Float64 destinations are preallocated identically outside windows and reused one cell at a time; maximum18432 payloadbytes at96. Each window retains only its final factor for outside-window Base.summarysize and residual/input scans. Output tokens/Dicts/TOML serialize outside timing; row reset to nothing is source reachability, not immediate collection. The three-factor probe has max55296 numeric output payloadbytes, plus fixed graph/counter/state records and serialization. No growing per-solve production ledger, callback copies, extra timed quality checks or long solver trajectory. No explicit GC inserted; measured GC/outliers preserved. Aggregate @timed GC allocation counters may include native allocations through Julia allocators; they are not a live native memory ledger.

Separate controls: one cold/nonretained early orientation exit; normalize=false and first/last eligible offdiagonal rejection on a fixed3x3 upper triangle (same import safeguards as structural tests); each policy has dense96 construction/copy, same-shape refactor, dense32 shrink, independent saved-copy refactor. Copies must start cache-empty, saved copies retain values while source refactors. Large/small control input snapshots before/after and state/graph scans outside timing; no extra API solves. Native orientation work of these refactors is included in the stated upper bound. All numeric fixtures for timed/probe/policy paths are exact old inputs, not new LPs.

Per process performance gates are fixed for ALL8cells: median paired whole-time ratio<=0.95; median bytes and events nonincrease; every measured AND warm final factor graph and all candidate/probe checkpoint graphs<=1.10 corresponding reference; measured compile/recompile0;>=3/7 faster; exact outputs/modes, unchanged inputs and128*n*eps(Float64)*max(1,||M||inf||x||inf,||rhs||inf) residual bound. Side timings, ratios, all samples, MAD/ranges, GC and nested phases retained. Transition combined graphs and transient seam peaks are reported separately, not silently substituted for single-factor graph gates. No universal speedup/full-native-memory claim.

On any first-process performance gate failure, stop fixed design: no second process, cache/fixture/normalization tuning. Only all8pass permits separately admitted reversed order, then both processes' gates plus>=10/14 faster per cell. Any later ordinary-BG/public/production proposal needs separate matched comparison and admission; this component study does not integrate production.

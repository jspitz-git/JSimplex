## Storage, failure and order review

Bulk import validates dimensions, CSC pointers and strictly increasing row IDs; builds inverse q and row degrees; and visits stable column IDs to populate sorted row incidences. Original logical column j maps to stable cid=q[j]. No packed intermediate, generic insertion loop, input retention, or coefficient conversion is introduced. Float64 payloads, including imported signed/explicit zeros and nonfinite values, are copied without arithmetic.

The row/column reciprocal relation is explicit: handles encode descriptor/offset while row_back stores physical gap-buffer position. Gap movement repairs each crossed handle's row_back. Block shifts repair each moved entry's row incidence. Relocation swaps extents while retaining the live descriptor ID and returns the old extent through the free donor descriptor. Split stages all33 tuples before clearing/writing either extent. Merge stages both prefixes before retaining either descriptor, repairs endpoints and handles, and performs no cascading sweep. Empty blocks unlink immediately.

Adjacent swaps merge stable-column incidence streams, save both tuples before writing, and update physical-row maps afterward. Rotation carries the moving row tuple through each affected column interval before changing maps; other rows' repaired handles remain consistent. These preserve the stopped read-only reference's stable-column meaning and first-to-last rotation direction. Copy creates independent child slabs, row buffers, maps, free lists, descriptors and scratch, including retained capacity.

Checked dimension/descriptor/handle/row growth occurs before numeric edits. New descriptor arrays, slab buffers and directories remain private until the applicable allocation sequence succeeds. Earlier successful reserves may remain published if a later reserve fails; live coefficients, logical order and reciprocal references are preserved. This is capacity-versus-live-state failure semantics, not whole-update rollback. The allocator seam is call-local and is not retained. Commit paths contain no explicit allocation requests, but arbitrary Julia OOM, boxing, specialization and tuple-splat behavior have not been tested and are not certified nonallocating.
